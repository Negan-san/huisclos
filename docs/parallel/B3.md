## Adaptateurs : prototypes exclusivement

Anonym-IA : NOM_PERSONNE et PRENOM_PERSONNE vers PERSON, NOM_SOCIETE vers
ORGANIZATION, DOB vers BIRTH_DATE, EMAIL et TELEPHONE vers leurs types existants.
DATE générique n'est pas une naissance. NUM_DOSSIER et identifiants ne remplacent
pas les règles et checksums du socle. Les composants NOM_VOIE, NUMERO_VOIE,
CODE_POSTAL et VILLE sont ignorés par ce prototype : les adresses entières viennent
de l'assembleur A2, pas d'un composant isolé abusivement déclaré adresse complète.
Ce choix peut sous-estimer l'apport d'un futur assembleur de composants Anonym-IA.

GLiNER : labels figés `person`, `organization`, `address`, `email`, `phone number`,
`date of birth`. Une ville seule n'a pas de label demandé. Les offsets fournis sont
décalés par fenêtre puis projetés ; aucune recherche de la première occurrence.
Les sources neuronales utilisent provisoirement la valeur technique `ner_camembert`
de l'énumération existante ; le vrai backend est conservé séparément dans chaque
payload. Les scores restent ceux de chaque modèle, sans calibration croisée.
A4 doit valider une intégration réelle avant adoption de ces adaptateurs.

FR : Standard reste le choix le moins coûteux sur ce dev saturé. Enhanced existant
et Anonym-IA égalent ses résultats sans gain marginal de couverture. GLiNER et
l'union ajoutent 101 caractères de surmasquage et dégradent les métriques de type.
Anonym-IA ajouté à GLiNER n'apporte rien ; GLiNER ajouté à Anonym-IA n'améliore
aucune couverture FR. Aucune option nouvelle ne remplit le critère B1 contre
Standard ou contre le CamemBERT actuel. Aucune troisième couche CamemBERT n'est
essayée : le meilleur profil FR ne laisse aucun caractère sensible découvert.

EN : Standard + GLiNER remplit le critère B1 contre Standard A2, le meilleur profil
anglais existant. Gain de deux entités entièrement couvertes, 42 caractères sensibles
supplémentaires protégés, cinq caractères de surmasquage supplémentaires. F2 partiel
0,903704 vers 0,914454. Différences appariées à 95 % après pseudonymisation :
couverture +0,014706 [0 ; 0,032473], fuite -0,016451 [-0,037632 ; 0], surmasquage
+0,000389 [0 ; 0,001180]. Ces intervalles incluent zéro : aucune significativité
affirmée, aucun résultat de généralisation ni validation aveugle.

Fuite EN par type, Standard vers GLiNER : CASE_NUMBER 55 vers 55, ORGANIZATION
34 vers 4, PERSON 4 vers 4, PHONE 13 vers 1 caractères ; zéro pour les autres types
évalués. Les cinq références privées encore exposées sont formulées dans une phrase,
avec un mot intermédiaire ou sans le libellé immédiat exigé par la règle A2.
Ce périmètre de contextes reste à revoir sur dev par A4. Aucun caractère auparavant
masqué n'est découvert par les profils retenus ou par l'union FR, y compris face
à chacun de ses constituants ; compte explicite dans `coverage_losses`.

## Audit, tests et handoff A4

- Neuf invariants passent : ajout exhaustif d'un candidat faible aux frontières,
  fenêtres répétées, projection Unicode, adresse FR entière et arrêt de champ,
  adresse EN, référence publique distincte du dossier privé, dates distinctes,

  trouve le téléphone entier ; `merge.trim` appelle `strip_borders`, qui retire la
  parenthèse initiale, conservant `202) 555-0186`. Un caractère annoté reste visible.
  Défaut déjà signalé dans les limites A2, reproduit indépendamment. Test d'abord
  rouge, conservé en `xfail(strict=True, raises=AssertionError)` avec motif précis.
  Aucun xfail de script de mesure ; le premier essai de fenêtre avait une erreur
  d'offset dans la fixture, corrigée sans exception au test.
- Les tests du benchmark vérifient offsets répétés et Unicode, coupure réelle de
  fenêtre, refus de troncature, politique des labels, immutabilité du plan,
  métriques calculées à la main, vraie substitution, répétitions incomplètes et
  modification des labels dans le code après préenregistrement.
- Contrôles généraux sous baseline_python : `pytest -q -p no:cacheprovider`,
  1584 passed, 1 xfailed (130,81 s) ; Ruff check et format conformes ; check_style

- Aucun téléchargement, aucune installation, aucun test/challenge/all ni lot
