## Décisions proposées

- D-AF-B1-1 Couverture complète : union des caractères réellement masqués, quel que soit le type prédit, sans vrai positif historique pour une mauvaise étiquette. Périmètre de comparaison : onze types ; CUSTOM et LOCATION publiés à part ; non sensible = hors de toute annotation ; aucun périmètre dépendant du profil ; un caractère visible empêche la couverture intégrale ; ratio sans dénominateur `null` (not applicable). Métriques historiques et résultats G7 inchangés.
- D-AF-B1-2 Pilote de robustesse : plan JSON figé et haché (langue du document, profils, seuils, comparaisons) ; trois stades séparés (détection, pseudonymisation automatique de toutes les propositions, alertes du contrôle final sans masquage) ; aucun humain simulé ; mode dev par défaut avec refus des corpus réservés ; mode gate sans texte, valeur, position ni identifiant ; référence d'un autre commit en processus séparé ; rapport séparé `robustness.json` compatible avec le schéma de `results.json`.
- D-AF-B1-3 Incertitude : bootstrap par document, 2 000 tirages, graine 45, mêmes tirages pour tous les profils d'un rapport ; tirages sans dénominateur écartés et comptés pour la couverture ; significativité seulement par un intervalle apparié qui exclut zéro.
- D-AF-B1-4 Protocole post-G7 : comparateurs nommés (Standard contre G7 `hybrid`, Enhanced contre G7 `hybrid_camembert`, Enhanced contre Standard, nouveau backend contre le meilleur profil retenu) ; critère d'ingénierie (fuite plus faible, couverture complète plus élevée, précision au moins référence moins deux points, surmasquage au plus référence plus un point) ; dev puis vérification des seuils avant toute mesure réservée, sans `--split all` ; C3 FR/EN après gel ; résultats séparés par langue.
- D-AF-B1-5 Contrat avec A2 : `DetectionConfig.document_language` (fr ou en, défaut fr), indépendant de la langue UI et du style de jetons ; sans ce champ, une demande EN échoue clairement.

## Limites et risques

- Le dev FR actuel est saturé pour les onze types : il ne départage pas Standard et Enhanced. Les gains éventuels de A1 à A4 devront apparaître sur des fixtures nouvelles et sur C3.
- La couverture compte des caractères et ne juge pas la ré-identification par le contexte ; un passage sensible non annoté compte comme surmasquage.
- Le pilote dépend des signatures actuelles `detect(text, config)`, `pseudonymize(text, detections)`, `final_check(result, detect_text)` et `check_threshold(threshold)`, ainsi que de `PRESETS` ; un changement de signature exige d'adapter `stage_outputs`.
- La révision CamemBERT est lue dans le cache local Hugging Face (`refs/main`) ; un modèle chargé depuis un autre chemin n'aurait pas de révision enregistrée.
