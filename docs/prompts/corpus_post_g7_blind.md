# C3 : rédaction aveugle bilingue après G7

Session neuve du 28 octobre 2026, piste B. Le pilote a confirmé le gel A4 au
commit dc5b04146c9217bdd09da5064091e0cf638f5b37 avant rédaction. Seuls AGENTS.md
et corpus/README.md ont été lus pour les conventions ; aucun résultat, règle de
détection, ancien corpus ou échange A/B n'a été consulté.

Le mandat est de rédiger huit dossiers fictifs français et huit anglais,
répartis entre consultation, correspondance, acte/projet et récapitulatif.
Chaque langue comporte six textes de 250 à 450 mots et deux de 800 à 1 200 mots.
Les conventions post_g7_fr_en_1.0 sont figées avant annotation dans le README
du lot réservé. Chaque occurrence sensible est annotée, puis les omissions et
bornes sont relues sans détecteur, mesure ou service d'annotation distinct.

Le constructeur indépendant transforme les seules sources nommées du lot en
deux challenge.jsonl, calcule les clés fictives et publie un manifeste avec
comptes et empreintes. Ses contrôles structurels n'évaluent aucune détection.
Les audits visibles ne contiennent aucun texte ni span du corpus. Les limites
d'un auteur unique et d'une même famille de modèle restent explicites.

Le lot est réservé à C3 puis aux scripts des gates. Aucun ancien split, code
métier, test ou environnement partagé ne doit être modifié. La clôture comprend
les contrôles communs, une nouvelle confirmation du gel, le fragment séparé
docs/parallel/C3.md et le commit « C3 : lot aveugle bilingue après gel ».
